# AI Resume Analyzer & Job Matcher

An AI-powered resume analysis and job matching application built with Python and Streamlit.

## Features

- Upload resume in PDF format
- Extract resume text automatically
- Detect job role from job description
- Match resume skills with job requirements
- Calculate resume-job match percentage
- Identify matching and missing skills
- Analyze skill gaps
- ATS score analysis
- Resume quality analysis
- Skill priority recommendations
- Smart project recommendations
- Skill Match Overview visualization

##  Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- PyPDF

## Project Purpose

This project helps students and job seekers understand how well their resume matches a particular job description.

It identifies missing skills and provides recommendations to improve the resume and prepare for the target role.
